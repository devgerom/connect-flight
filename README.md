# ✈️ ConnectFlight

Projeto desenvolvido para a **Atividade Avaliativa** da disciplina de **Programação para Web II**.

## 🛠️ Tecnologias
- React
- Vite
- React Router DOM
- CSS puro

## 📄 Páginas
- **Home** – Página inicial (fiel ao protótipo do Figma)
- **Destinos** – Lista de destinos disponíveis
- **Ofertas** – Pacotes promocionais
- **Contato** – Formulário de contato

```bash
npm install
npm run dev
